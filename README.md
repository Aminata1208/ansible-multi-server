# Gestion de configuration multi-serveurs avec Ansible

Projet de gestion centralisée de la configuration de plusieurs serveurs avec Ansible.

## Objectif

Automatiser et centraliser la configuration de serveurs Web, de base de données et de supervision à l'aide d'Ansible, en utilisant des rôles réutilisables et un inventaire multi-groupes.

## Technologies

- Ansible
- Ubuntu Server
- Git
- GitHub
- VirtualBox
